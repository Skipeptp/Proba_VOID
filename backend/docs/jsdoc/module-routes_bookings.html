Module: routes/bookings

Маршруты для работы с бронированиями тренировок.

Реализует запись клиента на занятие, просмотр истории бронирований, получение списка участников занятия и изменение статуса бронирования.

Methods

(async, static) createBooking(req, res) → {Promise.<void>}

Записывает клиента на тренировку.

Доступно только пользователям с ролью CLIENT. Проверяет наличие активного абонемента, остаток посещений и свободные места в группе. При успешной записи создаёт бронирование и уменьшает остаток посещений, если он используется.
