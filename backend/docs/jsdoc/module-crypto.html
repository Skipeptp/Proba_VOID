Module: crypto

Модуль шифрования и расшифрования данных.

Использует симметричный алгоритм AES-256-CBC. Ключ шифрования читается из переменной окружения AES_KEY_HEX.

(static) encrypt(value) → {Object}

Шифрует текстовую строку алгоритмом AES-256-CBC.

Для каждого вызова генерируется случайный вектор инициализации IV. Возвращает зашифрованное значение и IV в шестнадцатеричном виде.
