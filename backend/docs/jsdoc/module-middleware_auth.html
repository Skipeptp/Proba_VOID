(static) auth(req, res, next) → {void}

Проверяет JWT-токен и разрешает доступ только авторизованному пользователю.

Извлекает токен из заголовка Authorization в формате Bearer, проверяет подпись и срок действия. При успехе сохраняет payload токена в req.user.
