Methods

(async, static) login(req, res) → {Promise.<void>}

Выполняет вход сотрудника фитнес-центра.

Находит активную учётную запись сотрудника по логину, сравнивает введённый пароль с хешем из базы данных и создаёт JWT-токен сроком действия 8 часов.

В payload токена включаются идентификатор сотрудника, роль, employeeId и clientId, если он связан с клиентом.
