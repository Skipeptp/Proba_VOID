# Fitness Center Web App

Проект по курсовой работе: веб-приложение для фитнес-центра с автоматизацией записи клиентов, расписания, абонементов и личных достижений.

## Архитектура

- База данных: PostgreSQL (контейнер `db`).
- Backend: Node.js + Express (контейнер `backend`), REST API, JWT-аутентификация, роли пользователей.
- Frontend: React (Vite) SPA (контейнер `frontend`).
- Docker Orchestration: docker-compose поднимает три сервиса и сетку между ними.

### Модель данных

Схема описана в `db/init.sql` и реализует сущности из ТЗ: `client`, `employee`, `trainer`, `membership`, `membership_type`, `membership_freeze`, `workout_type`, `schedule`, `booking`, `hall`, `equipment`, `payment`, `achievement`, `training_program`, `review`.

### Роли и безопасность

- Роли БД: `dba`, `data_reader`, `data_writer`, `log_reader` с правами по регламенту.
- Роли приложения: `ADMIN`, `TRAINER`, `CLIENT`, `MANAGER`, `OWNER` (хранятся в таблице `role`).
- Пароли сотрудников хэшируются через bcrypt и не хранятся в открытом виде.
- Медицинские ограничения и личные достижения зашифрованы AES-256 (см. `backend/src/crypto.js`).
- Конфиденциальные системные секреты (JWT_SECRET, AES_KEY_HEX) берутся из `.env`, который не коммитится в git.

## Как запустить

1. Установи Docker и docker-compose.
2. Склонируй проект или скопируй папку `fitness-center` себе локально.
3. В каталоге `backend` создай файл `.env` со следующими переменными (пример):

   ```env
   PORT=4000
   DB_HOST=db
   DB_PORT=5432
   DB_NAME=fitness_center
   DB_USER=fitness_user
   DB_PASSWORD=fitness_password
   JWT_SECRET=super_secret_jwt_key
   AES_KEY_HEX=32bytes_key_in_hex_XXXXXXXXXXXXXXXXXXXXXXXXXXXX
   BCRYPT_ROUNDS=10
   ```

4. В корне проекта выполни:

   ```bash
   docker-compose build
   docker-compose up
   ```

5. Сервисы:

   - БД: `localhost:5432`
   - Backend API: `http://localhost:4000/api`
   - Frontend: `http://localhost:3000`

## Что и как доработать под курсовую

1. **База данных**
   - При необходимости добавь недостающие поля из ТЗ в `init.sql`.
   - Добавь индексы, триггеры аудита и хранимые процедуры согласно разделам документа.

2. **Backend (Node.js)**
   - Расширь маршруты: CRUD для клиентов, абонементов, платежей, достижений, отзывов.
   - Добавь в JWT не только `id` и `role`, но и `client_id` для клиентов и `employee_id` для сотрудников, чтобы не передавать `client_id` руками.
   - Реализуй логику контроля абонементов при записи на тренировку (остаток посещений, активность абонемента и т.п.).

3. **Frontend (React)**
   - Сделай отдельные дашборды для администратора, тренера, менеджера (например, по роли рендерить разные компоненты).
   - Добавь формы:
     - Регистрация клиента (для администратора или публичная страница).
     - Продажа абонемента и просмотр статуса.
     - Фиксация личных достижений тренером.
     - Просмотр истории посещений и достижений клиентом.

4. **Документация**
   - На основе структуры проекта заполни разделы отчета: описание архитектуры, используемые технологии, ER-диаграмму по `init.sql`, диаграммы вариантов использования (по ролям: клиент, тренер, администратор, менеджер, владелец).

## Основные шаги разработки

1. Спроектировать ER-модель (сделано в `init.sql`).
2. Реализовать схему в PostgreSQL и роли доступа.
3. Поднять backend с базовой аутентификацией и ролевой моделью.
4. Реализовать ключевые бизнес-процессы в API: расписание, запись, абонементы, достижения.
5. Сделать фронтенд для трех ролей: клиент, тренер, администратор.
6. Оформить и описать все в курсовом отчете.
